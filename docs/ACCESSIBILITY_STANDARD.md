# Accessibility Standard

Accessibility is architecture.

Required:
- semantic HTML;
- logical reading/focus order;
- visible focus;
- keyboard operation;
- usable touch targets;
- meaningful alt text;
- captions/transcripts for meaningful media;
- no essential meaning conveyed only by colour, animation, hover or sound;
- prefers-reduced-motion support;
- responsive duplicates removed from accessibility tree;
- sticky UI never obscures critical content.

For 3D, provide a semantic non-3D representation of essential facts and relationships.

If 3D cannot be the sole accessible representation, it is progressive enhancement.
