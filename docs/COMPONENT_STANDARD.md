# Premium Component Standard

A component is premium when purpose, interaction, motion, visual treatment, accessibility and performance resolve as one system.

Every premium component defines:
- purpose
- lead Authority
- interaction inputs
- responsive behaviour
- keyboard/touch behaviour
- reduced-motion behaviour
- fallback
- performance intent

## Before/after slider

Requirements:
- pointer/touch drag;
- keyboard adjustment;
- visible focus;
- accessible description of both states;
- no essential meaning dependent solely on dragging;
- no mobile scroll conflict;
- reconstruction classification where relevant.

## Scrollytelling

Requirements:
- semantic HTML copy;
- scroll drives state, not inaccessible reading-order changes;
- no scroll-jacking;
- reduced-motion uses discrete state changes;
- camera transitions settle into readable compositions.

## GLB storytelling

Requirements:
- historical purpose;
- evidence metadata where relevant;
- LOD/instancing considered;
- lazy-load heavy assets;
- static/poster fallback;
- narrative remains usable without 3D.

Motion must communicate:
time, location, causation, transformation, chronology, focus or revelation.

Otherwise remove it.
